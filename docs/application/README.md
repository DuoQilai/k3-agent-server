# 应用入口

## 1. 当前入口

当前应用层直接使用 DSH Web UI：

```text
访问设备浏览器
→ SSH 隧道
→ http://127.0.0.1:3080
→ DSH 对话、文件和工具任务
```

本项目暂时没有独立的 Web 前端、API 网关或移动端应用。

## 2. 使用前提

使用应用层之前应完成：

1. 模型服务部署；
2. DSH Agent 服务部署；
3. DSH 模型提供方接入；
4. 访问设备到 K3 的 SSH 隧道。

具体访问步骤见项目 [README](../../README.md) 的“下次访问”和[运维手册](../operations-manual.md)。
