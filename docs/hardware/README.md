# 硬件要求

## 1. 目标设备

本流程面向 SpacemiT K3 Pico-ITX，要求系统报告的架构为 `riscv64`。脚本会在架构不匹配时停止，不会尝试在其他平台模拟部署。

## 2. 内存与存储

当前默认模型是 DeepSeek-R1-Distill-Qwen-1.5B Q4_0，模型文件约 1 GB。除模型外，还需要保存 Node.js、DSH 依赖、编译产物和运行数据。

部署前应检查：

```bash
free -h
df -h "$HOME"
```

建议为整个部署预留至少 10 GB 可用空间。更换更大的 GGUF 模型时，必须按实际模型文件、上下文缓存和运行峰值重新评估内存与磁盘；本手册不假定所有 K3 配置都能运行任意模型。

## 3. 网络

K3 至少需要：

- 首次部署时访问软件源、npm registry、Node.js 构建站和模型镜像；
- 日常使用时能被访问设备通过 SSH 连接；
- 使用云端模型时能够访问对应模型提供方。

3080 和 8080 不需要直接开放到局域网或公网。

## 4. 散热与供电

长时间推理会持续占用 CPU 和内存。设备应使用稳定供电和适合持续负载的散热条件。不同机箱、风扇和环境温度差异较大，本项目不提供未经实测的温度或功耗阈值。

如出现非正常降频、重启或进程被系统终止，应先检查设备温度、供电和内存，再排查应用配置。

## 5. 外设与加速器

当前固定流程使用 SpacemiT 提供的 `llama.cpp` 软件包，不要求额外 PCIe GPU。GPU、NPU、VPU 或其他加速器的启用方式不在当前用户手册范围内。
